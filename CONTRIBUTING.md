## Code of Conduct

Please read and follow our [Code of Conduct](CODE_OF_CONDUCT.md) to foster a welcoming and inclusive community.

## How to Contribute

- Fork the repository and create your branch from `main`.
- If you've fixed a bug or added a feature, ensure appropriate tests are included.
- Open a pull request with a clear description of your changes.

## Reporting Issues

If you find a bug or have a feature request, please open an [issue](https://github.com/kinnoo-project/kinnoo/issues). Include as much detail as possible to help us address the problem quickly. If you would also like to contribute to resolving the bug or implementing the requested feature, leave a note within the issue stating that you will be contributing, and add a link to your pull request once you have changes you want to merge.

## Submitting Pull Requests

- Ensure your code passes all tests and follows the style guide.
- Reference the related issue in your pull request description.
- Keep pull requests focused and concise.

## Development Setup

1. Clone the repository
2. Create and activate a virtual environment
3. Install dependencies from `requirements.txt`

## Coding Guidelines

- Write clear, readable, and well-documented code.
- Follow the project's structure and naming conventions.
- Add or update tests for new features or bug fixes.

## Style Guide and Commits

- Follow PEP8 for Python code.
- Use meaningful commit messages.
- Use concise, descriptive commit messages.
- Reference pull requests within the relevant issue. Always make sure your pull request is associated with an issue. If an issue doesn't exist, create one.
