# Kinnoo (Public Mock Split)

This `mock-public/` directory is a candidate layout for the future public `kinnoo-project/kinnoo` repository.

## Scope in this mock

- CLI code: `src/kinnoo/`
- Web frontend: `web/`
- Public docs: `docs/`
- Public tests: `tests/` (CLI/web-oriented only)
- Public scripts: `scripts/` (release/dev-tooling subset)
- Public manifests: `FEATURES.txt`, `TASKS.txt`, `TESTS.txt` (renumbered public slice with original-id notes)

## Out of scope (stays private)

- `server/`
- `iac/`
- `lambda_handler.py`
- private operational/deployment scripts and workflows
- private internal notes
