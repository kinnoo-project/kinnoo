    Schema definition:
    | Field              | Required | Type         | Constraints                                      |
    |--------------------|----------|--------------|--------------------------------------------------|
    | name               | yes      | string       | non-empty, valid package name (alphanumeric, -)  |
    | version            | yes      | string       | valid semver (e.g., "0.1.0", "1.2.3")            |
    | entrypoint         | yes      | string       | non-empty file path                              |
    | runtime.language   | yes      | string       | e.g., "python"                                   |
    | runtime.version    | yes      | string       | version constraint (e.g., ">=3.10")              |
    | runtime.type       | yes      | string       | e.g., "one-shot"                                 |
    | dependencies       | yes      | list[string] | can be empty list                                |
    | inputs.type        | yes      | string       | e.g., "text"                                     |
    | outputs.type       | yes      | string       | e.g., "text"                                     |

  description: |
    Add first-class Go language support across the Kinnoo CLI workflow for both source-based
    and precompiled-binary agents. This includes scaffolding support in `kinnoo init`, manifest
    support in `kinnoo.yaml`, runtime execution in `kinnoo run`, and language-aware validation in
    `kinnoo run --preflight`.

    Scope for `kinnoo init`:
    - `--language go` generates a runnable Go agent skeleton with default entrypoint `main.go`.
    - `--language go --framework gemini | chatgpt | claude-chat` generates one-shot chat templates
      in Go that map to the corresponding provider SDK patterns.
    - `--language go --framework mcp-server` generates a minimal Go MCP server template.
    - `--language go --framework mcp-client` generates a minimal Go MCP client template.

    Scope for `kinnoo run` and preflight:
    - `kinnoo run` executes basic Go source agents using `main.go` as the default entrypoint.
    - `kinnoo run --preflight` validates Go toolchain/runtime expectations for source agents.
    - `kinnoo run` also executes precompiled Go binaries when declared in manifest entrypoint.
    - `kinnoo run --preflight` performs binary compatibility checks (OS and architecture match,
      executable format sanity, executable permissions where applicable) and fails fast with
      actionable diagnostics when the binary cannot run on the current device.

    - Architecture checks should parse binary metadata (Mach-O/ELF/PE) instead of relying only on
      filename conventions.
    - Preflight should distinguish hard-fail conditions (OS/arch mismatch, missing execute bit)
